# Paywall Bypass (userscript)

A Violentmonkey / Tampermonkey userscript that adds a floating **Bypass Paywall** button and menu commands to supported news sites. Each option opens the current article in an archive or reader service in a new tab:

- UnWall
- archive.today / archive.is / archive.ph
- RemovePaywall
- Wayback Machine (archive.org)

The floating button can be toggled from the userscript manager's menu. The setting is saved.

## Install

1. Install [Violentmonkey](https://violentmonkey.github.io/) (or Tampermonkey).
2. Open the raw script: [paywall-bypass.user.js](https://raw.githubusercontent.com/Kebie/paywall-bypass-userscript/main/paywall-bypass.user.js). Your userscript manager will offer to install it.
